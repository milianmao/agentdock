## 关键事实速查

- 单一 Go 二进制同时是 MCP Server + HTTP 控制面 + 设备执行器；桌面端只是控制面板。
- 依赖方向严格单向，`internal/tool/*` 不 import `internal/app`。
- 工具注册、分组与可用性门只在一处讲 → 详见 [核心功能模块](../02-功能结构和策略/核心功能模块.md)。
- 无中间件依赖：并发靠文件锁，多进程（Core + Arbiter + CLI）安全协作。
- 状态根 `~/.agentdock`，工作区默认 `~/AgentDock`。
