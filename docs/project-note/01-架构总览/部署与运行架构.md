# 部署与运行架构

## 运行形态一览

| 形态 | 入口 | 传输 | 典型场景 |
|---|---|---|---|
| 本机服务 | `agentdock serve`（默认子命令） | HTTP `127.0.0.1:8765` | ChatGPT/Claude 网页版接本机 |
| stdio 客户端 | `agentdock serve --stdio` 或 `AGENTDOCK_STDIO=true` | stdio | Claude Desktop / Codex CLI 等本地 MCP 客户端 |
| 容器 | `docker compose up -d` | HTTP `0.0.0.0:8765` | VPS、内网常驻 |
| 桌面托管 | macOS App / Windows 托盘启动 Core | HTTP + 本地 IPC | 普通用户一键安装 |
| Nexus 节点 | 已配对后的 Core | 出站 WebSocket/HTTPS | 云端统一调度多设备 |

`agentdock` 没有 daemon 双进程：**同一进程既是 MCP server 也是设备执行器**。Windows 例外，托盘与 Core 是两个进程，靠本地 IPC 通信。

## CLI 子命令

`cmd/agentdock/main.go:27 run` 按顺序拦截，未命中则落到 `runServer`：

| 子命令 | 实现 | 说明 |
|---|---|---|
| `--version` / `version [--json]` | `command_version.go` | 版本与构建信息 |
| `update [--check\|--progress-json\|--local-archive …]` | `internal/selfupdate` | 自更新；`--progress-json` 让 stdout 成为机器事件流 |
| `service <status\|start\|stop\|restart\|autostart>` | `command_service.go` | 托管服务控制 |
| `tunnel <status\|start\|stop\|restart\|regenerate\|configure\|autostart>` | `internal/desktopruntime` | cloudflared 隧道 |
| `component <…>` | `command_component.go` | cloudflared 组件管理 |
| `config <…>` | `internal/desktopruntime` | 配置读写 |
| `skill bootstrap --bundle <dir>` | `command_skill.go` | 首次安装内置 Skill |
| `nexus pair\|status` | `command_nexus.go` | 设备配对与状态 |
| `install` / `uninstall` | `internal/installer` | 事务式安装/卸载 |

`selfupdate.HandleInternalCommand` 在**最前面**拦截，Windows 更新后的内部命令不会被当成用户子命令解析。

## 启动顺序（`cmd/agentdock/server.go:28`）

精确顺序，任一步的语义不可互换：

| # | 步骤 | 位置 | 失败处理 |
|---|---|---|---|
| 1 | `os.Unsetenv("AGENTDOCK_NEXUS_ENDPOINT")` / `_TOKEN` | `server.go:33-35` | — |
| 2 | `config.FromEnv()` → flag 覆盖 → `ParseMCPAppsMode` → `cfg.Normalize()` → `cfg.ValidateAuth()` | `server.go` | 返回错误退出 |
| 3 | `nexusbridge.Load(cfg.AgentDockHome)`，成功则**覆盖** `cfg.NexusEndpoint` / `NexusDeviceToken` | `server.go` | 非 `os.ErrNotExist` 仅记日志 |
| 4 | `logx.Setup` → `startupdiag.Log` | `server.go:95` → `cmd/agentdock/internal/logx/logx.go:8` | — |
| 5 | `selfupdate.RepairDesktopRuntimeIfNeeded` | `server.go` | **只告警不阻断** |
| 6 | `app.NewRuntime(cfg)` → `mcp.NewServer(runtime, cfg)` | `server.go` | 按逆序 Close 已建组件后退出 |
| 7 | `cfg.Stdio` → `serveStdio`；否则 `httpx.Serve` | `server.go:164` / `internal/httpx/server.go:21` | 返回错误 |
| 8 | `AGENTDOCK_RUNTIME_ROOT` 非空 → 并行 `desktopcontrol.Serve` | `server.go` | 与 HTTP 同 `done` chan（容量 2），任一退出 cancel 另一个 |
| 9 | 已配对 → goroutine `nexusbridge.NewClient(...).Run(serviceCtx)` | `server.go` | 由重连循环自行恢复 |

**步骤 1 为什么存在**：`AGENTDOCK_NEXUS_ENDPOINT` / `AGENTDOCK_NEXUS_TOKEN` 是已废弃的环境变量凭据。进程启动即清除，保证配对文件 `~/.agentdock/nexus/device.json` 是唯一凭据来源，避免旧部署脚本把凭据泄漏给子进程。

**关闭顺序**：`cancelServices()` → `bridgeWG.Wait()` → `Runtime.Close()`。Nexus 客户端仍有在途 invoke 时关闭 Runtime 会 panic。

## 环境变量

### 核心

| 变量 | 默认 | 说明 |
|---|---|---|
| `AGENTDOCK_HOME` | `~/.agentdock` | 状态根。所有 Skill/Plugin/任务/凭据/锁都在这里 |
| `AGENTDOCK_DEFAULT_DIR` | `~/AgentDock` | 默认工作区根 |
| `AGENTDOCK_HOST` | `127.0.0.1` | 监听地址。容器内必须 `0.0.0.0` |
| `AGENTDOCK_PORT` | `8765` | 监听端口 |
| `AGENTDOCK_AUTH_TOKEN` | 空 | Bearer token。非 loopback 监听时必填 |
| `AGENTDOCK_LOG_LEVEL` | `info` | `debug`/`info`/`warn`/`error` |
| `AGENTDOCK_STDIO` | `false` | 切 stdio 传输 |
| `AGENTDOCK_MCP_APPS_MODE` | `full` | `full` / `compact` / `off`，控制 MCP Apps UI 资源 |
| `AGENTDOCK_RUNTIME_ROOT` | 空 | 非空时启用桌面控制 socket |
| `AGENTDOCK_TRUSTED_PROXY_CIDRS` | 空 | 逗号分隔，反向代理下取真实客户端 IP |

### 浏览器

| 变量 | 默认 | 说明 |
|---|---|---|
| `AGENTDOCK_BROWSER_ENABLED` | `false` | 开启 `browser_session`/`browser_act`/`browser_snapshot` |
| `AGENTDOCK_BROWSER_EXECUTABLE_PATH` | 自动探测 | Chromium/Chrome 路径 |
| `AGENTDOCK_BROWSER_CDP_URL` | 空 | 连已有 CDP 端点 |
| `AGENTDOCK_BROWSER_REUSE_EXISTING_CDP` | `false` | 复用已有 CDP 会话 |

### OAuth

| 变量 | 默认 | 说明 |
|---|---|---|
| `AGENTDOCK_OAUTH_ENABLED` | `false` | 启用 OAuth 授权服务器，持久化到 `<home>/oauth/state-v1.json` |
| `AGENTDOCK_SERVER_URL` | 空 | 对外基址，决定 OAuth issuer 与回调 URL |
| `AGENTDOCK_OAUTH_ACCESS_TOKEN_TTL` | 见代码默认 | access token 有效期秒数，支持"永不过期"特殊值 |

### ACP

| 变量 | 默认 | 说明 |
|---|---|---|
| `AGENTDOCK_ACP_ENABLED` | `false` | 开启 `acp_*` 工具族 |
| `AGENTDOCK_ACP_PROFILES_JSON` | 空 | 多 profile JSON 数组；为空时回退旧单 profile 环境变量 |
| `AGENTDOCK_ACP_DEFAULT_PROFILE` | 首个 profile | 默认 profile ID |
| `AGENTDOCK_ACP_MAX_CONCURRENT_PROMPTS` | `2` | 每 profile 并发上限 |
| `AGENTDOCK_ACP_INTERACTION_TIMEOUT_MS` | `300000` | 交互请求超时 |

### 命令环境

| 变量 | 默认 | 说明 |
|---|---|---|
| `AGENTDOCK_COMMAND_ENV_FROM_ENV_JSON` | 空 | JSON map，把宿主环境变量映射进 `exec_command` 子进程 |

### 保留变量（不可由用户配置覆盖）

| 变量 | 归属 | 判定函数 |
|---|---|---|
| `SKILL_DATA_DIR` | Skill 运行时 | `config.IsReservedSkillEnvironmentKey`（`internal/config/paths.go:100`） |
| `PLUGIN_DATA_DIR` | Plugin 运行时 | `config.IsReservedPluginEnvironmentKey`（`internal/config/paths.go:107`） |

## 目录布局

```text
<AGENTDOCK_HOME>/                    默认 ~/.agentdock
├── skills/<name>/                   受管 Skill 内容（当前版本）
├── data/skills/<name>/              Skill 私有持久数据
├── data/skills/.plugin/<plugin>/<skill>/
├── data/plugins/<plugin>/           Plugin 数据（版本无关，升级保留）
├── plugins/<name>/<version>/        已安装 Plugin 内容
├── plugins/state/plugins/           Plugin 正式 state
├── plugins/state/plugins/transactions/  ActivationTransaction journal
├── plugins/state/plugins/removals/  purge tombstone
├── plugins/run/plugins/<name>/      可写运行代（runtime snapshot）
├── plugins/tmp/plugins/             候选包暂存
├── plugins/locks/plugins/           三级文件租约
├── env/<scope>.env                  环境变量作用域
├── tasks/<id>.json                  任务状态
├── nexus/device.json                Nexus 配对凭据
├── oauth/state-v1.json              OAuth 客户端与授权持久化
├── public-artifacts/<id>/           公开制品不可变快照
├── locks/                           通用文件锁
├── tmp/                             临时文件
└── logs/                            轮转日志

<和工作区>/                           默认 ~/AgentDock
```

Plugin 六类目录全部经 `os.OpenRoot` + `Lstat` 拒绝符号链接，权限强制 `0700`。

## HTTP 端点

| 路径 | 方法 | 鉴权 | 说明 |
|---|---|---|---|
| `/` | GET | 否 | 状态页（HTML） |
| `/healthz` | GET | 否 | `{ok,version}` |
| `/.well-known/mcp.json` | GET | 否 | MCP server card |
| `/.well-known/mcp/server-card.json` | GET | 否 | 同上（兼容路径） |
| `/.well-known/oauth-authorization-server` | GET | 否 | OAuth 元数据 |
| `/.well-known/oauth-protected-resource/mcp` | GET | 否 | Protected resource 元数据 |
| `/register` | POST | 否 | 动态客户端注册 |
| `/oauth/authorize` | GET/POST | 否 | 授权页 |
| `/oauth/token` | POST | 否 | Token 端点 |
| `/oauth/callback` | GET | 否 | 上游 OAuth 回调 |
| `/context` | GET | 按配置 | `agentdock_context` 的 HTTP 镜像 |
| `/internal/runtime/*` | GET/DELETE/POST | 按配置 | Runtime API，见 `04/服务层与IPC通信.md` |
| `/artifacts/public/<id>/<file>` | GET | 签名 URL | 制品下载 |
| `/mcp` | POST/GET | 按配置 | MCP Streamable HTTP 端点 |

超时与限制（`internal/httpx/server.go:newHTTPServer`）：`ReadHeaderTimeout=10s`、`ReadTimeout=15s`、`IdleTimeout=60s`、`MaxHeaderBytes=1MiB`，优雅关闭预算 10s。

`/mcp` 请求体上限 **1 MiB**（`internal/httpx/mcp_endpoint.go:65-70`），超限返回 413 而非 JSON-RPC 错误。

## 构建

```bash
make build            # ./bin/agentdock，注入 Version/Commit/BuildDate
make check            # fmt-check + test + test-scripts + vet + build
make test             # go test ./...
make race             # go test -race ./...
make docker-build     # runtime 目标镜像
make docker-browser-build
```

`BUILD_VERSION` 默认 `0.0.0-dev`；Release CI 从 Git Tag 注入真实版本。

## 安装

| 平台 | 入口 | 契约 |
|---|---|---|
| Linux/macOS | `scripts/install/install.sh` | 只做平台识别、交互、下载校验、OS bootstrap；事务交 `agentdock install` |
| Windows | `scripts/install/install.ps1` + `AgentDockSetup-<arch>.exe` | 脚本保留 UAC / DPAPI / Registry / session broker 外层适配；generation、shim、manifest、事务由 Go Installer Engine 拥有 |

分发地址 `https://download.nexusdock.co`（R2），GitHub Release 仅供人工下载。`latest.json` 与 `components/v1/catalog.json` 是机器分发契约。

`scripts/governance/inventory.yaml` 把公开入口标记 `public_contract: true` + `deletable: false`：`install.sh`、`install.ps1` 不得改名删除。

## 容器内运行

```bash
docker compose up -d                        # 主服务
docker compose --profile cloudflare-quick up -d
docker compose --profile cloudflare-named up -d
```

容器内注意：

- `AGENTDOCK_AUTH_TOKEN` 无默认值：compose 变量为空时启动失败，这是刻意设计。
- `AGENTDOCK_HOST` 必须是 `0.0.0.0`，否则容器外不可达。
- `umask 077` 由 `docker-entrypoint.sh` 设置，保证新建文件不越权。
- 首次启动自动 `agentdock skill bootstrap --bundle /usr/local/share/agentdock/core-skills` 安装 4 个内置 Skill。
