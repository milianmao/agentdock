## 无外部中间件

AgentDock **不使用**数据库、消息队列、缓存服务器。所有状态落在文件系统：

| 状态 | 位置 | 格式 |
|---|---|---|
| 任务 | `<home>/tasks/*.json` | JSON，单任务一文件 + 索引 |
| Skill 内容 | `<home>/skills/<name>/` | 目录树 + `SKILL.md` |
| Skill 数据 | `<home>/data/skills/<name>/` | 任意 |
| Plugin | `<home>/plugins/<name>/<version>/` | ZIP 解包 + manifest |
| Plugin 数据 | `<home>/data/plugins/<name>/` | 任意（版本无关，升级保留） |
| 环境变量 | `<home>/env/*.env` | dotenv 风格 |
| Nexus 配对 | `<home>/nexus/device.json` | JSON |
| OAuth 状态 | `<home>/oauth/state-v1.json` | JSON |
| 公开制品 | `<home>/public-artifacts/` | 文件 + `metadata.json`（`publicartifacts/store.go:194`） |
| 更新事务 | `<root>/update/transaction.json` | JSON journal |
| 锁 | `<home>/locks/`、`<root>/update/transaction.lock` | 文件锁 |

**并发控制全部靠文件锁**，没有进程内共享数据库。这让多进程（Core + Arbiter + CLI）能安全协作。

## 容器镜像

`Dockerfile` 分 5 个阶段：

| 阶段 | 基础镜像 | 内容 |
|---|---|---|
| `build` | `golang:1.26.5` | 编译 `agentdock`、`agentdock-arbiter` 等 |
| `runtime-base` | `node:22.17` | bash/git/jq/ripgrep/fd/python3/pnpm；uid/gid 10001；预建 `~/.agentdock`、`~/AgentDock`；`packaging/build-core-skill-bundle.py` 生成 `/usr/local/share/agentdock/core-skills`；`HEALTHCHECK agentdock-healthcheck` |
| `dev` | `runtime-base` | + `build-essential` + Go 工具链 |
| `browser` | `runtime-base` | + Chromium + 中日韩字体；`AGENTDOCK_BROWSER_ENABLED=true`、`AGENTDOCK_BROWSER_EXECUTABLE_PATH=/usr/bin/chromium` |
| `browser-test` | `browser` | xvfb 下跑 `go test -tags browser_integration` |
| `runtime` | `runtime-base` | 唯一发布目标 |

`docker-entrypoint.sh` 做两件事：`umask 077`，以及首启 `agentdock skill bootstrap --bundle /usr/local/share/agentdock/core-skills`。

## 编排

`docker-compose.yml` 主服务 `agentdock`：

| 配置 | 值 | 原因 |
|---|---|---|
| `AGENTDOCK_AUTH_TOKEN` | **必填**（无默认） | 容器默认 `0.0.0.0` 监听，无 token 即公网裸奔 |
| `AGENTDOCK_HOST` | `0.0.0.0` | 容器内必须监听全网卡 |
| `shm_size` | `1gb` | Chromium 需要大 `/dev/shm` |
| volume | `agentdock_home`、`agentdock_workspace` | 状态与工作区分离 |
| healthcheck | 30s 间隔，`agentdock-healthcheck` | 供编排与发布门使用 |

Profile：`cloudflare-quick`（临时域名，`AGENTDOCK_SERVER_URL` 留空）、`cloudflare-named`（固定域名，需 `TUNNEL_TOKEN`）。

## CI/CD

| 工作流 | 触发 | 关键点 |
|---|---|---|
| `ci.yml` → `go` | push/PR | ubuntu/macos/windows 三平台矩阵；`go test ./... -count=1 -timeout=3m`；Linux 额外 `gofmt -l` 检查、ACP steering 竞态回归（`-count=20`）、`go test -race ./... -timeout=3m`、`go vet`、`go build ./cmd/agentdock`、`make test-scripts` |
| `ci.yml` → `browser-integration` | 同上 | xvfb + `-tags browser_integration -race ./internal/tool/browser ./internal/app` |
| `ci.yml` → `container` | 路径触发 | `scripts/test/test-docker-images.sh` |
| `release.yml` | `push tags v*` / `workflow_dispatch` | 20+ job 链：SignPath 审核 → 源码包 → Linux/macOS/Windows 构建 → cloudflared 组件校验 → macOS App → Windows Setup → 发布门 → 分阶段发布 → 容器 → GitHub Release |
| `cloudflared-component.yml` | 组件发布 | 独立于主版本节奏 |
| `codeql.yml` | 定时/PR | 静态分析 |
| `r2-retention.yml` | 定时 | R2 制品保留策略 |
| `windows-installer.yml` | 手动/路径 | Windows 安装器 E2E |

## 平台特性矩阵

| 能力 | Linux | macOS | Windows |
|---|---|---|---|
| 本地 IPC（control socket） | Unix socket | Unix socket | 命名管道 + SHA-256 校验 |
| 进程树终止 | 进程组 kill | 进程组 kill | `descendantProcessIDs` 递归 |
| PTY | `pty` | `pty` | ConPTY |
| 桌面 App 更新 | 不适用 | 整体换 `.app` + handoff/result 文件 | Inno Setup 二次分发 |
| 安装根 | `/opt/agentdock`（或 `install.sh` 指定） | `~/Library/Application Support/AgentDock` | `%LOCALAPPDATA%\Programs\AgentDock` |
