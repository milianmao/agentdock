## 版本号语义

`internal/releaseversion/version.go:9 Normalize` 是唯一的规范化入口：

| 规则 | 行为 |
|---|---|
| 缺 `v` 前缀 | 自动补 |
| 非 SemVer | 返回 `false`，调用方**不得**退化成字符串比较 |
| 前导零（`01.2.3`） | 拒绝 |
| 段数非 3 | 拒绝 |

`updateengine/contract.go:151 NormalizeVersion` / `:162 ValidateVersion` 是更新链路的同一逻辑。

`buildinfo.Current()`（`buildinfo.go:27`）返回 `{Version, Commit, BuildDate, GoVersion, Platform}`；`Commit` 在未注入时回落到 `debug.ReadBuildInfo()` 的 `vcs.revision` —— 这就是为什么本地 `go build` 也能显示真实 commit。
