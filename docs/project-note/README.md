## 项目的五个硬事实

1. **单二进制 Core + 原生桌面端**：`agentdock` 提供 `/mcp`（StreamableHTTP 或 stdio），31 个工具涵盖文件、命令、任务、Skill、Plugin、MCP、浏览器、ACP、产物发布。
2. **所有持久状态在 `~/.agentdock`**，0700 目录 + 0600 文件 + 原子写；11 个状态载体各有独立的并发模型。
3. **事务一律 journal-first，提交点是单次原子 rename 或单次 durable write**；崩溃恢复只做前向收敛。
4. **版本权威是 Git tag**，不是源码里的字符串（`buildinfo.Version` 默认 `0.0.0-dev`）。
5. **当前仓库没有 git tag**：`v1.0.0-rc.3` 只存在于提交主题中。任何"当前版本"的判断都要带着这个前提。
